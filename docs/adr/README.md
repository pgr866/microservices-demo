# Architecture decision records

Each decision that shapes the experiment or the platform gets a short record here: its context, what was decided and what follows from it. Files are numbered in order (`NNNN-title.md`). A decision that changes isn't rewritten: a new record replaces it, and the old one says `Superseded by NNNN`.

## Template

```markdown
# NNNN. Title

- Status: Proposed | Accepted | Superseded by NNNN
- Date: YYYY-MM-DD

## Context

## Decision

## Consequences
```
